# QA-01 CI build validation

## Scope

The pull-request and `main` CI job now builds all workspace artifacts with the
repository Node and pnpm setup before running checks and tests. CI has
read-only contents permission and does not commit or push formatting changes.

## Executable evidence

The workflow step is defined in [.github/workflows/ci.yml](../../.github/workflows/ci.yml)
as `pnpm build`, after `pnpm install --frozen-lockfile` and before `pnpm check`.
The step supplies the synthetic `NEXT_PUBLIC_DASHBOARD_REQUEST_TIMEOUT_MS=15000`
value required to prerender the dashboard; this is not a production approval.
The existing integration job remains separate and retains its PostgreSQL
service.

Local validation:

```text
NEXT_PUBLIC_DASHBOARD_REQUEST_TIMEOUT_MS=15000 CI=1 pnpm build
CI=1 pnpm check
```

No CI run or deployment artifact upload is claimed by this local change.
