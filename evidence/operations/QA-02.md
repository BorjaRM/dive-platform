# QA-02 API test discovery

## Scope

The API unit-test configuration discovers only API source tests. Workspace
dependency tests are not collected by the API suite and remain owned by their
workspace scripts.

## Executable evidence

The scope is defined in [apps/api/vitest.config.ts](../../apps/api/vitest.config.ts)
with `src/**/*.spec.ts`; `node_modules`, `dist`, `coverage`, and e2e specs are
excluded explicitly.

Validation commands:

```text
pnpm --filter @dive-center/api exec vitest run --config vitest.config.ts --reporter=verbose
pnpm --filter @dive-center/identity test
```

The API command must be run without relying on a cached test result when
reviewing the discovered file list.
